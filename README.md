# Multiple Tools. One CLI.
Gojo wraps several common open source tools used for C and C++ development into a single unified CLI. It is inspired
from Rust's [`cargo`](https://doc.rust-lang.org/cargo/commands/index.html), though in reality it is a simple wrapper over [CMake](https://cmake.org/). I suppose that makes gojo a...
meta meta build system? The idea is to

1. Provide one unified CLI for several distinct tools
2. Improve the common dev workflow (build, run, test)
3. Create easy to reproduce project environments with declarative syntax
4. Make it easier for beginners to get started with C and C++

Gojo is tested on MacOS and Ubuntu, and should work on any Linux distro.

# Install
## Pre-compiled Binary
To install gojo, paste the following command in your terminal:

```console
$ curl --proto '=https' --tlsv1.2 -sSf -L https://raw.githubusercontent.com/whuffman36/gojo/refs/heads/main/install/install.sh | sh
```

This command fetches the install script from this repo and runs it in your shell. The script also downloads all the necessary dependencies (mostly other common C/C++ CLI tools) for you. You can see the install script [here](install/install.sh).

As the script tells you, you will need to refresh your terminal after installing gojo in order to actually use it. You can do that with the following command on Linux:

```console
$ source ~/.bashrc
```

On MacOS (Or any system that uses zsh as the shell), the command is:

```console
$ source ~/.zshrc
```

## Build From Source
Alternatively, you can clone this repo and build gojo from source:

```console
$ git clone <insert link here>
$ cd gojo
$ make install
```

Gojo requires some other dependencies that need to be installed before you can build and run it. Because each system is different, I will leave it up to you to learn how to get each dependency installed on your system:

- CMake
- Conan
- clang-tidy (optional)
- clang-format (optional)
- cppcheck (optional)
- git (optional)

Many of these will likely already be on your system if you are a developer. If you choose to omit the dependencies marked as optional above, gojo will still build and run but some functionality will be limited, namely the commands `gojo check` and `gojo fmt`.

Again, you must refresh your termninal after the installation to use gojo.

Linux:

```console
$ source ~/.bashrc
```

On MacOS (Or any system that uses zsh as the shell):

```console
$ source ~/.zshrc
```

# Using Gojo
Start a new project in your current working directory:

```console
$ gojo init <name>
```

Decide all of the project settings in an interactive mode:

```console
$ gojo init --interactive
```

You can see all the commands available in gojo by running

```console
$ gojo --help
```

as well as seeing all of the subcommands, arguemnts, and options for any command:

```console
$ gojo <command> --help
```

Finally, you can read about all of the project settings available in the gojo.toml config file with

```console
$ gojo info
```
